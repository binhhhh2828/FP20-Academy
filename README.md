# FP20 Academy – Academic Performance Analysis

## Project Description
This project analyzes academic performance data from FP20 Academy to evaluate teaching quality, student outcomes, and the impact of strategic decisions such as school expansion and curriculum adjustments. The analysis aims to identify performance trends, strengths, and inefficiencies to support data-driven educational planning.

---

## Business Questions
- How did student performance change after the academy scaled up?
- Which subjects are the strengths and weaknesses of FP20 Academy?
- Do current assessment methods accurately reflect student performance?
- How does student performance vary across academic terms (Fall, Spring, Summer)?
- What insights can support better curriculum planning and resource allocation?

---

## Dataset
The dataset consists of student academic records collected across multiple academic years.

Key fields include:
- Academic Year
- Student
- Subject
- Teacher
- Assessment Type
- Score
- Pass / Fail Status
- Academic Term

> The data used in this repository is sampled and anonymized for demonstration purposes.

---

## Analysis Approach
- Data cleaning and validation
- Aggregation of performance metrics by year, subject, teacher, and term
- Calculation of key metrics:
  - Average score
  - Pass rate
- Trend analysis across academic years
- Subject-level and assessment-level comparison
- Identification of performance gaps and bottlenecks

---

## Key Metrics Explained

### Average Score
Mean score achieved by students within a given subject, period, or assessment type.

### Pass Rate
Percentage of students who passed assessments within a defined scope.
